以下为项目自行生成的衍生产物，不涉及第三方版权，**可自由上传**：

## 七、HuggingFace 私有数据集策略

### 7.1 仓库

- **仓库**：`NZC415/wm-dataset`（私有）
- **用途**：跨服务器快速下载，仅本人访问
- **已上传**：training_metadata/（manifest、config、audit）、scripts/（处理脚本）

### 7.2 上传原则

1. **衍生文件优先**：manifest、caption、脚本、配置 — 无版权风险，已上传
2. **视频数据**：私有仓库仅供本人跨服务器下载，但仍受原数据集许可约束。上传前确认：
   - CC-BY-NC 类：可上传，附原许可和署名
   - 研究许可类：技术上可上传到私有仓库供本人使用，但需注意许可条款中是否明确禁止任何形式的再分发
   - YouTube 类：版权风险最高，建议不上传原视频，仅保留 manifest + 原始 URL
3. **大文件策略**：5+TB 视频上传 HF 不现实（LFS 配额、带宽），建议：
   - 小数据集（NoXi 37GB、H2O 0.4GB、DexYCB 0.9GB、Seamless 25GB）可上传
   - 大数据集（MIRA 5.4TB、Ego-Exo4D 10.1TB、OpenVidHD 4TB）保留在原始存储，跨服务器用 rsync/共享 FS

### 7.3 跨服务器复现流程

```bash
# 1. 在新服务器上 clone 私有数据集（manifest + 脚本）
hf download NZC415/wm-dataset --repo-type dataset --local-dir wm_dataset_meta

# 2. 用脚本和 manifest 从原始来源下载视频
# 3. 运行 build_unified_manifest.py 复现训练数据
```
