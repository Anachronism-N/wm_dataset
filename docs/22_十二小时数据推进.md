## 可自动下载队列

仓库已有五份 Project Aria 官方 URL 导出，均带文件大小和 SHA1。只取训练最有用的 `video_main_rgb` 时：

| 数据集 | Preview 视频 | 预计体积 | 本地状态 | 行动 |
|---|---:|---:|---|---|
| ADT | 236 | 23.9GB | 未下载 | 网络恢复后先取 5 条 pilot |
| Aria Everyday Activities | 143 | 19.8GB | 未下载 | P0，日常行为覆盖好 |
| HOT3D Aria | 198 | 17.8GB | 未下载 | P0，手物交互 |
| HOT3D Quest | 226 | 7.2GB | 未下载 | P0，手物交互，成本最低 |
| Nymeria | 1,100 | 1.06TB | 未下载 | 只取小规模 pilot |

使用 `dataset_tools/download_queue.py` 生成队列后，下载器支持 Range 续传、原子完成、大小和 SHA1 校验。URL 是带期限的 CDN 签名 URL，网络恢复后必须先用 1 条记录验证是否过期；过期时需要由官方 CLI 重新导出。

统一入口为 `scripts/download_project_aria.sh`。脚本会显式设置代理、先下载并校验 1 条、通过后继续队列，并将完整日志写入 `dataset/download_logs/`、将最新摘要写入 `docs/23_Project_Aria下载日志.md`。默认 `pilot` 只处理 25 条；`all` 会处理 1,903 条、约 1.124TB，必须显式指定。

```bash
# 默认：25 条、约 6.35GB
bash scripts/download_project_aria.sh pilot

# 全量：1,903 条、约 1.124TB
bash scripts/download_project_aria.sh all
```
